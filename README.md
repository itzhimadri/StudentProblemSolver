# 📚 StudyFlow — Student Assignment Dashboard

**Organize your assignments. Stay ahead of deadlines. Achieve more.**

StudyFlow is a modern, responsive student assignment dashboard designed to help students organize academic tasks, track deadlines, monitor progress, and manage their studies from one place.

Built with HTML, CSS, and vanilla JavaScript, StudyFlow provides a clean and intuitive interface that makes academic planning simpler and more productive.

🌐 **Live Demo:** [Open StudyFlow](file:///c%3A/Users/USER/OneDrive/Desktop/student_assignment_dashboard/index.html)

📦 **Repository:** [StudentProblemSolver on GitHub](https://github.com/itzhimadri/StudentProblemSolver)

---

## ✨ Key Features

- **📊 Smart Dashboard** — View total assignments, tasks due today, upcoming deadlines, and completed assignments at a glance.
- **📝 Assignment Management** — Add, edit, delete, complete, and reopen assignments.
- **🔍 Instant Search** — Find assignments by title, subject, or notes.
- **🏷️ Subject and Status Filters** — Organize tasks and quickly find what needs attention.
- **📅 Interactive Calendar** — Navigate between months and select dates to organize your academic schedule.
- **⏰ Upcoming Reminders** — Keep track of approaching assignment deadlines.
- **📈 Progress Tracking** — Monitor completed work and stay focused on your academic goals.
- **💾 Local Data Storage** — Save assignment data in your browser using `localStorage`.
- **📱 Responsive Design** — Access the dashboard on desktop, tablet, and mobile screens.
- **🚀 Ready-to-Explore Dashboard** — Sample assignments help demonstrate the interface immediately.

## 🚀 Getting Started

Follow these steps to run StudyFlow on your computer.

### Prerequisites

- A modern web browser
- Git (optional, for cloning the repository)
- Visual Studio Code (recommended for development)

### Option 1: Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/itzhimadri/StudentProblemSolver.git
   ```

2. Open the project folder:

   ```bash
   cd StudentProblemSolver
   ```

3. Open `index.html` in your browser, or open the folder in Visual Studio Code and use the Live Server extension.

4. Start managing your assignments!

### Option 2: Use the Live Website

Visit the deployed website:

**https://itzhimadri.github.io/StudentProblemSolver/**

If the website has not been published yet, enable GitHub Pages in the repository settings first.

## 💾 Data Storage and Privacy

StudyFlow uses the browser's `localStorage` to save assignment information.

- Assignment data is stored locally in the browser on the device being used.
- There is no cloud database or automatic synchronization between devices.
- Clearing browser site data may remove saved assignments.
- Other users or devices will not automatically receive your locally saved tasks.

**Tip:** Avoid using private or sensitive information in assignment notes on shared devices.

## 🧭 How to Use StudyFlow

1. Open the dashboard.
2. Review your assignment statistics and upcoming deadlines.
3. Select **Add Assignment** to create a task.
4. Enter the assignment details, subject, and due date.
5. Search or filter tasks when needed.
6. Mark assignments as completed when you finish them.
7. Reopen completed tasks or edit existing assignments whenever necessary.
8. Use the calendar and dashboard summaries to plan your workload.

*Available actions depend on the functionality implemented in the current version.*
